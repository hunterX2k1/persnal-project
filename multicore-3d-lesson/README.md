# Multi-Core Architecture in 3D

A single-page, narrated 3D lesson on multi-core computer architecture (Three.js + the browser's Web Speech API).

Open `index.html` in a browser and press **Play lesson**. The narrator reads each step while the 3D chip animates; drag to orbit, Space to play/pause, ←/→ to change steps.

Lessons: why multicore · pipelining · instruction-level parallelism · memory hierarchy · cache coherence (MESI) · on-chip interconnect · hardware multithreading · synchronization & consistency.
